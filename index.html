Deploy Admin Controls to Vercel

This Admin Portal is 100% self-contained and ready to deploy as a public or team internal website on Vercel or any static web host.

# 1. Navigate to the admin project directory:
cd C:\Users\JorgeContreras\.gemini\antigravity\scratch\zengine-power-tools-admin
# 2. Deploy instantly using Vercel CLI:
npx vercel --prod

Features included in Vercel package:

  • ✓ Pre-configured vercel.json with clean URL rewrites and serverless /api/config and /api/login endpoints.
  • ✓ Universal CORS Headers: Enables Chrome and Edge extensions installed by staff worldwide to fetch published changes.
  • ✓ Secure Passphrase Login: Default administrator passphrase georgesnow2026 (override with ADMIN_PASSWORD env variable).
  • ✓ One-Click JSON Sync: Use the "Export JSON" and "Import JSON" buttons at the top of the page to transfer your custom profiles and keybindings between the web portal and your browser extension.
