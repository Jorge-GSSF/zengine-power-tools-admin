Privacy Policy for Zengine Power-Tools

Last updated: October 28, 2026 • Version 1.8.31

1. Overview

Zengine Power-Tools is a private productivity and navigation browser extension engineered specifically for authorized staff members of the George Snow Scholarship Fund interacting with Zengine HQ (platform.zenginehq.com). We prioritize data privacy, operational security, and confidentiality.

2. Information Collection and Handling

Zengine Power-Tools operates under a strict Zero Data Harvesting architecture:

  • No Personal Data Collection: The extension does not collect, track, log, or sell any personal identifying information, student records, banking data, or browsing history.
  • Local Session Authentication: To perform authorized searches and navigate disbursement forms, the extension reads the active user's existing session token directly from the authenticated Zengine browser tab. This token is used strictly within the user's local browser context to communicate directly with Zengine's authorized API.
  • No External Transmission: Session tokens and student records are never transmitted to any third-party server, tracking service, or external analytics provider.

3. Browser Permissions & Storage

The extension requests only the minimum permissions required for operation:

  • Storage: Used to save staff user interface preferences (such as keyboard shortcut rebindings and search display size) in local browser storage (chrome.storage.local / chrome.storage.sync).
  • ActiveTab & Scripting: Used to inject keyboard navigation listeners and assistive side-panel helpers solely on authorized Zengine domains (*.zenginehq.com).
  • Host Permissions: Strictly scoped to Zengine API endpoints and secure organizational configuration synchronization.

4. Third-Party Sharing

We do not share, sell, rent, or monetize any user data or institutional records under any circumstances. The extension does not contain third-party advertising, telemetry libraries, or marketing trackers.

5. Scope and Workspace Restrictions

The extension enforces strict organizational workspace boundaries and remains dormant when navigating outside authorized operational workspaces.

Contact & Inquiries:
For questions regarding this privacy policy or administrative configuration, please contact the George Snow Scholarship Fund technical administration team at jcontreras@scholarship.org.
